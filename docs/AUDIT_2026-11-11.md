# Functional audit, 2026-11-11

The original code imported ESX A-scans and suggested landmarks, but did not produce
physical biometry or keratometry tables. This update supplies a batch CSV workflow
for research estimates. Axial length is the strongest supported automatic output.
Choroid/sclera and retina still need manual inspection. Absolute physical accuracy
in chickens remains unvalidated.

## Tests run

- All 20 local real ESX files, 42 eye-exams, matched to known manual SpikeFinder
  landmarks by subject, eye and full normalized examination timestamp.
  All 504 available landmark intensities matched the original export within 0.001
  intensity units (maximum discrepancy below 5e-13), checking real scan decoding/averaging.
- Batch CLI: all 20 files and 42 eyes exported, no file failures. Both the legacy
  58-column export and the new analysis/device tables were produced.
- Leave-one-animal-out refitting of marker biases on the compact labelled dataset:
  118 eye-exams from 2017/2020, and 156 from 2015/2016. No test animal supplied its
  own bias correction. Detector rules were developed using this collection, so this
  is internal cross-validation, not an independent external validation cohort.
- 14 automated tests cover existing functionality, geometry calculations, device metadata extraction, batch partial failure, duplicate file paths,
  truncated XML, wrong scan length, review-file isolation and corrupt review positions.

For the 42 end-to-end ESX comparisons, axial length median absolute disagreement
was 0.59 micrometres, maximum 21.81. Choroidal thickness median disagreement was
1.47 micrometres, maximum 72.35. These use a shipped profile fitted on overlapping
animals and are regression checks, not held-out accuracy estimates.

Internal cross-validation on the 118 recent eye-exams:

| Measurement | Median absolute error (µm) | 95th percentile (µm) | Maximum (µm) | Within 25 µm |
|---|---:|---:|---:|---:|
| Axial length, whole-eye index to RPE | 0.59 | 2.95 | 100.78 | 99.2% |
| Choroidal thickness | 1.76 | 107.91 | 193.53 | 89.8% |
| Lens thickness | 1.13 | 21.25 | 215.91 | 94.9% |
| Retinal thickness | 1.76 | 587.18 | 650.00 | 73.7% |

These are disagreements against hand landmarks converted with the same constants,
not independently measured anatomical lengths. Small median errors coexist with
large outliers. The 42 end-to-end eye results produced no detector review flags,
despite some large thickness errors. Every unconfirmed eye is therefore marked
requires_review=1 in the biometry table.

Older conventions are worse: 2015/2016 lens thickness was within 25 µm in 69.9% of
156 eye-exams. Retina had valid ordered boundaries in only 121/156; among those,
only 15.7% agreed within 25 µm. Use an era-appropriate profile and inspect boundaries.

Keratometry was excluded at the user's request.

## Defects addressed

- Added named, unit-labelled measurements and explicit conversion assumptions.
- Preserved repeated device biometry results, rather than overwriting all
  observations with the final measurement's result.
- Reject scan-size inconsistencies and non-finite values instead of padding/skipping.
- Reject truncated XML instead of silently accepting only completed examinations.
- Batch failures now appear in a manifest and cause a nonzero exit status.
- Deduplicate repeated input paths. Analysis rows expose duplicate examination keys
  across different source files without silently selecting among conflicting scans.
- Review filenames use a path hash to prevent same-basename overwrites; invalid
  restored sample positions cannot index outside the scan.
- Unknown detector profile names fail explicitly instead of silently using an
  uncalibrated detector. Patient identity fields reset between patient elements.

## Decisions and limits

Historical R code supplied the 1250 samples/mm OPL factor and tissue indices. It
also contained positional-column mistakes, reversed vitreous subtraction, an OS
calculation referencing OD data, and an unexplained aqueous-index subtraction of
0.1. Those computations were not copied. Whole-eye-index length to RPE and
segment-summed length to RPE/sclera are separate outputs with explicit endpoints.
The whole-eye-index conversion is an additional documented assumption; it is not
represented as an exact reproduction of the old R total-eye calculation.

Remaining priorities: independently verify the scan scale and anterior reference;
agree the axial endpoint and tissue indices; collect physical/repeatability checks;
review posterior boundaries; validate physical lengths against independent references.

The audit used an internal `research/audit_biometry.py` script and private labelled
data, which are not distributed in this public repository. Automated synthetic tests
are included and run with `python -m pytest -q`. No raw data are published.
See [workflow and definitions](BIOMETRY.md) for use and remaining parser/batch limits.
